# Fabrieksjacht

Speurtocht-game voor geschiedenis 3 mavo: boekje 1 "De industriële samenleving in Nederland" en boekje 2 "Sociale zekerheid en verzorgingsstaat", H1.

- Spel: https://jboersen88-dot.github.io/fabrieksjacht/
- Docent: https://jboersen88-dot.github.io/fabrieksjacht/docent.html · scorebord: bord.html
- `vragen.js`: meerkeuze (MC), combinatievragen met 6 paren (COMB) en open vragen met tip (OPEN)
- `fotos.js`: volgorde waarin de stukjes van elke foto zichtbaar worden (nu nog een standaard raster)
- `f/1..6.jpg`: de foto's van de plekken (nu nog tijdelijke plaatjes)
- Worker `fabrieksjacht-spel` (map `worker/` buiten de site): codes, pestkaarten, ranglijst; opslag in een Durable Object
- Nakijken van open vragen gaat via de AI-worker van de escape room.
